# Security policy

## Supported versions

Security fixes target the latest stable release and the latest beta while a beta is active. Upgrade to the latest version in your release channel before checking whether a problem still occurs; older versions do not receive guaranteed backports.

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/funkydude755/sbar/security/advisories/new) form. Reports are private to the project maintainers and invited collaborators until an advisory is published.

Include the affected version, operating system, reproduction steps, and the expected security impact. Share a minimal example without real credentials or private terminal contents. Please avoid public issues or pull requests containing vulnerability details before maintainers have assessed the report.

Reports are reviewed as maintainer availability permits; there is no guaranteed response time or bounty program.
